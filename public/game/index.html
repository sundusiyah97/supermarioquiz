🎯 Tujuan Petualangan:

Berlari dan melompatlah melewati rintangan, kumpulkan koin emas, kalahkan musuh dengan menginjaknya, dan selesaikan 10 Checkpoint Kuis untuk membuka garis FINISH!

⌨️ Kontrol Single Player:

  • Panah Kiri / Kanan: Bergerak
  • Spasi / Panah Atas: Melompat
  • Shift: Berlari Cepat
  • ESC: Pause Permainan

👥 Kontrol Multiplayer (Split Screen):

  • Pemain 1 (Kiri): A (Kiri), D (Kanan), W (Lompat), Shift Kiri (Lari)
  • Pemain 2 (Kanan): ← (Kiri), → (Kanan), ↑ (Lompat), Enter (Lari)
💡 Aturan Checkpoint Kuis: Jika jawaban benar (+100 poin), perjalanan berlanjut. Jika salah, kamu akan diberikan soal pengganti yang berbeda sampai berhasil menjawab dengan benar!
